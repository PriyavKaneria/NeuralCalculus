# Priyav Kaneria blog reader

Use this skill when a user asks about articles, projects, or ideas published on
https://priyavkaneria.com.

## Instructions

1. Start from the site's homepage, archives, categories, tags, or sitemap to
   locate the relevant published article.
2. Treat each article's canonical URL and publication date as the source of
   truth. Do not infer unpublished material from repository files or page
   titles alone.
3. Summarize in your own words and cite the article URL for factual claims.
4. If the requested information is not present in the public site, say so
   rather than filling gaps with assumptions.

## Scope

This is a read-only public-content skill. The site does not expose an API,
agent action, authenticated resource, or MCP server.
